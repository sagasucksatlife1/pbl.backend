View Results

The Problem

Traditional portfolio optimization models like Markowitz assume:

  • Linear relationships between assets
  • Independent variables with no complex interactions
  • Static behavior across different market conditions
  • Normally distributed returns with stable variance

But real financial markets are complex and nonlinear — with fat tails, volatility clustering, and regime changes.

The Solution

Machine learning models that learn directly from market structure:

Random Forest

Ensemble of decision trees that naturally models non-linear interactions and feature importance

Neural Networks

Deep learning architecture for universal function approximation in complex market regimes

Capabilities

  • Predict portfolio risk with higher accuracy than linear models
  • Capture nonlinear variable interactions (volatility × beta, momentum × market cap)
  • Improve asset allocation by predicting downside risk
  • Quantify feature importance for interpretable risk attribution

How It Works

Model Performance Analysis

🌲 Random Forest — Excellent Performance (R² ≈ 0.97)

  • Decision trees naturally model non-linear relationships without assumptions
  • Captures interaction effects (volatility × beta) that linear models miss entirely
  • 100-tree ensemble reduces variance while retaining flexibility
  • Robust to outliers and doesn't require feature scaling

🧠 Neural Network — Poor Performance (Negative R²)

  • Negative R² means the model performs worse than predicting the mean
  • Insufficient data: neural nets need 10,000+ samples; this dataset has ~1,000
  • High parameter count (64-32-16 layers) causes overfitting on small datasets
  • Feature scaling required — volume (millions) vs returns (decimals) confuse gradients

How to Fix the Neural Network

  • Standardize features using z-score normalization before training
  • Simplify architecture to 2 layers (32-16) to reduce parameter count
  • Add dropout (0.3) and L2 regularization to combat overfitting
  • Use early stopping on validation loss with patience=10
  • Collect more data — target 10,000+ observations across market regimes
